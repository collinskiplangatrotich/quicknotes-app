# QuickNotes App

QuickNotes is a lightweight, responsive single-page web application designed for quick daily note-taking. Users can add notes under distinct categories, perform real-time text searches, track character limits, delete individual notes, or clear all notes at once. All data is saved persistently in the browser using `localStorage`.

## Features
- **Categorized Notes**: Assign category tags (`Personal`, `Work`, or `Study`) with distinct color-coded indicators.
- **Form Validation**: Immediate error messaging for empty entries or notes exceeding 200 characters.
- **Live Keyword Search**: Instant filtering of saved notes matching user input.
- **Local Storage Persistence**: Automatic saving and loading so notes survive page reloads.
- **Responsive Flexbox Design**: Optimized layout that stacks cleanly on screens narrower than 600px.
- **Clear All Option**: Fast bulk deletion with a browser safety prompt.
